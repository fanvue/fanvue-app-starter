# Sicherheitsrichtlinie (Security Policy)

Wir nehmen die Sicherheit unserer Projekte und Daten sehr ernst. Wenn du eine Sicherheitslücke entdeckt hast, melde sie uns bitte direkt und vertraulich, bevor du sie öffentlich machst.

## Unterstützte Versionen

| Version | Unterstützt          |
| ------- | -------------------- |
| Aktuell | :white_check_mark:   |
| Älter   | :x:                  |

## Sicherheitslücken melden

Bitte erstelle **kein öffentliches Issue** für sicherheitsrelevante Schwachstellen, Token-Leaks oder Zugangsdaten.

Nutze stattdessen eine der folgenden Möglichkeiten:

1. **GitHub Security Advisory (bevorzugt):**  
   Reiche den Bericht diskret über den Reiter **Security** -> **Report a vulnerability** im Repository ein.
2. **Per E-Mail:**  
   Sende die Details direkt an:  
   **Agencylevelup2025@gmail.com**

### Was die Meldung enthalten sollte:
- Eine kurze Beschreibung der Schwachstelle.
- Schritte zur Reproduktion (Proof of Concept, Befehle oder Screenshots).
- Mögliche Auswirkungen auf das System oder die Daten.

Wir bemühen uns, eingehende Meldungen schnellstmöglich zu prüfen und eine Lösung bereitzustellen.
